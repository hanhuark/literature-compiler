# Data Policy

`literature-compiler` is intended for authorized, provenance-aware literature data compilation.

## Paper Access

The project should not bypass paywalls, publisher access controls, institutional authentication, or license restrictions. When a paper is not open access, obtain it through authorized university or personal access, then link local files or Zotero attachment paths into the case registry.

## What Can Be Committed

Safe repository contents include:

- Paper metadata.
- Case configuration files.
- Zotero item keys and BibTeX exports.
- Local file references that do not expose restricted files.
- Extracted quantitative data with provenance.
- Synthetic figures and open example assets.

## What Should Not Be Committed

Do not commit restricted publisher PDFs or figures unless redistribution is allowed. When in doubt, keep restricted assets local and commit only metadata plus extracted, attributed quantitative values.
