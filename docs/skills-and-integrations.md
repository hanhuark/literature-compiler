# Skills And Integrations

`literature-compiler` is a Python package, not an AI-agent plugin. These skills and integrations are optional workflow accelerators that can help a researcher use the repository more effectively.

## Recommended Research Workflow

1. Use literature-search and domain skills to define inclusion criteria.
2. Use authorized access and/or Zotero to collect papers.
3. Use `literature-compiler` to register papers, digitize figures, compile data, and plot comparisons.
4. Use engineering and academic review skills to check assumptions, source quality, and interpretation.

## Skills And Plugins

| Skill or plugin | Role in this project |
| --- | --- |
| Mechanical Engineering Research / Thermal-Fluid Research Workflow Plugin | Heat-transfer assumptions, boiling-regime checks, correlation validity, physical sanity checks, reproducible research coding, and figure interpretation. |
| Academic Research Skills | Broader literature workflow support: search strategy, source verification, synthesis, paper writing, review, revision, and publication-oriented documentation. |
| Deep Research | Systematic search planning, candidate screening, citation tracing, source grading, and synthesis. |
| Zotero plugin | Search local Zotero, export BibTeX, map Zotero item keys to `paper_id`, retrieve attachment paths, and read indexed full text when explicitly requested. |
| GitHub plugin | Create the repository, manage issues and pull requests, publish branches, and track development. |
| Browser plugin | Inspect local notebooks, documentation pages, or browser workflows when visual verification is useful. |
| Spreadsheets plugin | Inspect and export compiled literature tables in CSV/XLSX-friendly formats. |
| Documents and Presentations plugins | Build reports, review documents, or slide decks from compiled literature data. |
